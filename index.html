🔗 DBot XML Bridge — Export Predictions to Deriv DBot

How this works: When your prediction engine fires, this bridge generates a ready-to-import DBot XML file pre-configured with the predicted digit, the correct contract type, and your current market/stake settings. Barriers are fixed at 1 for Digit Over and 8 for Digit Under for optimal win probability.
  1. Start Analysis on the Digit Analysis tab and wait for predictions (needs 50+ ticks)
  2. Configure the DBot XML settings below
  3. When a signal fires, click Generate & Download DBot XML
  4. Go to dbot.deriv.com → My Bots → Import and load the file
  5. Run the bot — barrier & contract type already match your prediction

📖 DBot Import Guide

Step 1: Open https://dbot.deriv.com in your browser (same browser, new tab)

Step 2: Click the bot name dropdown at the top left → Import bot

Step 3: Select the downloaded deriv_signal_bot_DIGIT_X.xml file

Step 4: Verify the settings in DBot (market, contract type, barrier, stake)

Step 5: Click Run bot — DBot will trade based on the prediction configuration

💡 Tip: Barriers are fixed at Over 1 and Under 8 for maximum win probability (~80%). For fully automated real-time execution, use the Signal-Gated Bot on the Trading Bot tab instead.

⚡ Faster Alternative: Signal-Gated Auto-Bot

Instead of manually importing XML into DBot, use the built-in Signal-Gated Bot on the Trading Bot tab. It runs directly in this platform and:

  • Uses the same Deriv WebSocket connection already established
  • Reads prediction signals in real-time (zero delay)
  • Only places trades when signal meets your STRONG / MODERATE threshold
  • Auto-sets barriers to 1 (Over) or 8 (Under) for best win probability
  • Supports Martingale factor multiplier, fixed stop loss, fixed take profit, consecutive loss guard

→ Go to Trading Bot tab → Enable "Only trade on signal" → Start Bot
